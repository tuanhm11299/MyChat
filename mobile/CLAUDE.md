# mobile: CLAUDE.md

Kotlin Multiplatform. Standalone Gradle build (not part of pnpm). Source of truth:
`docs/architecture/mobile-kmp.md`. The owner is learning KMP, so prefer clear, idiomatic,
well-commented code over clever code, and explain KMP-specific choices in comments.

## Structure
- `shared/`: all non-UI code. `commonMain` first; `androidMain`/`iosMain`/`jvmMain` only for `actual`s
  and platform engines. Entry point: `MyChatSdk.kt` (manual wiring, no DI framework).
- `shared/.../contracts/`: `@Serializable` mirrors of `packages/contracts`. Keep field names identical.
- `androidApp/`: Jetpack Compose UI only. `iosApp/`: SwiftUI only (Xcode project generated by XcodeGen
  from `project.yml`; never commit `.xcodeproj`).
- Dependency versions: `gradle/libs.versions.toml` only.

## Rules
- Shared APIs called from Swift: `suspend fun` + `@Throws(CancellationException::class)`, return
  sealed classes for states. Never swallow `CancellationException`.
- Every shared feature has a `commonTest` using Ktor `MockEngine` (see `ServerStatusCheckerTest`).

## Commands
```sh
./gradlew :shared:jvmTest              # any OS
./gradlew :androidApp:assembleDebug    # needs Android SDK
# iOS: macOS + Xcode, see iosApp/README.md
```

Guides: `docs/guides/kmp-add-feature.md`, `docs/guides/kmp-for-beginners.md`.
